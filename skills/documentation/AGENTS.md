# Agent Rules: Documentation (v5.0.0)

Rules for consistent, searchable, and accurate technical documentation.

## [doc-001] Single Source of Truth
Avoid duplication; use cross-links for shared components.

## [doc-002] Visual First
Every complex flow must be accompanied by a Mermaid diagram.

## [doc-003] Code Snippet Lifecycle
Ensure code snippets use placeholders `<VARIABLE_NAME>` instead of hardcoded dev values.
