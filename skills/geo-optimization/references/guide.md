# GEO 地理位置优化与本地化深度指南

针对多地域业务及跨境应用的地理位置优化策略。

## 1. 本地 SEO 基础 (Local SEO)

### 核心要素
- **GMB (Google My Business) 优化**: 准确的名称、地址、电话 (NAP)。
- **本地关键词**: 包含地名、行政区名的搜索词分析。
- **本地引用 (Local Citations)**: 在当地商录、目录网站建立统一的信息。

## 2. 多语言与多地区优化 (International SEO)

### 核心实施
- **Hreflang 标签**: 正确声明页面的语言和地理变体, 防止重复内容问题。
- **URL 结构策略**:
  - **ccTLD** (`example.cn`): 本地信任度高。
  - **Subdirectory** (`example.com/zh/`): 权重集中, 维护成本低。
  - **Subdomain** (`zh.example.com`): 适合完全独立的地区系统。

## 3. 地理定向 (Geotargeting)

### 技术手段
- **IP 定向**: 基于用户 IP 自动推荐语言及货币。需保留用户手动切换权利。
- **CDN 边缘逻辑**: 在 CDN 端通过边缘脚本 (Edge Function) 进行地理重定向。
- **浏览器语言侦测**: 利用 `navigator.language` 进行初次引导。

## 4. 本地化内容策略 (Localization)

### 超越翻译
- **文化适配**: 尊重当地文化、禁忌及表达习惯。
- **本地货币与支付**: 集成本地支付方式 (如支付宝、微信、Klarna)。
- **合规性**: 遵守当地数据法规 (GDPR, CCPA 等)。

## 5. 常规检查清单

- [ ] 是否在所有页面的 `<head>` 中正确配置了 Hreflang?
- [ ] 本地商铺信息在所有主要平台是否保持 NAP 一致性?
- [ ] 是否提供了该地区特有的货币标识及配送说明?
- [ ] 测试 IP 定向是否能在不同地区的代理下正确工作?
