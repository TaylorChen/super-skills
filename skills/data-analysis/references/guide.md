# 数据分析与商业洞察深度指南

从数据清洗到商业决策支持的全流程实战。

## 1. 数据准备与清洗 (Data Cleaning)

### 核心步骤
- **处理缺失值**: 删除、填充(均值/中位数/回归)或保留。
- **异常值检测**: 利用 Z-Score、箱线图 (IQR) 识别并处理异常点。
- **数据转换**: 特征缩放 (Normalizing)、哑变量处理 (One-hot Encoding)。
- **重复数据**: 识别并剔除业务逻辑上的重复记录。

## 2. 统计分析基础 (Statistics)

### 核心指标
- **集中趋势**: 均值, 中位数, 众数。
- **离散程度**: 标准差, 方差, 极差。
- **相关性**: 皮尔逊相关系数 (Pearson correlation)。
- **假设检验**: P-Value、T 检验、卡方检验。

## 3. 数据可视化 (Data Visualization)

### 图表选择建议
- **趋势分析**: 线图 (Line Chart)。
- **比例分布**: 饼图 (Pie Chart) 或 环形图。
- **对比分析**: 柱状图 (Bar Chart)。
- **相关性探索**: 散点图 (Scatter Plot)。
- **多维对比**: 雷达图 (Radar Chart) 或 热力图 (Heatmap)。

## 4. 商业洞察提取 (Business Insight)

### 分析模型
- **AARRR (海盗模型)**: 获取、激活、留存、收益、推荐。
- **RFM 模型**: 最近一次消费 (Recency)、消费频率 (Frequency)、消费金额 (Monetary)。
- **SWOT 分析**: 优势, 劣势, 机会, 威胁。
- **漏斗分析**: 识别转换环节中的关键流失点。

## 5. A/B 测试 (A/B Testing)

- **实验设计**: 控制变量、随机分组。
- **样本量计算**: 确保结果具备统计学显著性。
- **指标选择**: 核心指标 (OEC) 与防御指标。

## 6. 数据分析检查清单

- [ ] 数据源是否可靠, 采样是否具有代表性?
- [ ] 是否已处理明显的异常值和错误脏数据?
- [ ] 结论是否基于统计学显著性支持而非偶然?
- [ ] 可视化报告是否易于非专业人士理解其商业寓意?
