# 原型设计与交互体验深度指南

旨在沟通需求、验证交互并指导开发的系统化原型设计。

## 1. 原型设计的三个阶段

### 低保真原型 (Wireframe)
- **目标**: 确定页面布局、功能占位和基本逻辑。
- **工具**: 白板, 手绘, Balsamiq, Figma (简单线框图)。

### 高保真原型 (Mockup)
- **目标**: 确定视觉风格、色彩标准、字体规范及品牌氛围。
- **工具**: Figma, Adobe XD。

### 可交互原型 (Interactive Prototype)
- **目标**: 模拟真实的交互体验, 验证跳转逻辑和用户反馈。
- **工具**: Figma (Prototype mode), Axure RP, Protopie。

## 2. 交互设计原则 (UX Principles)

- **一致性 (Consistency)**: 全局 UI 组件、术语及反馈模式统一。
- **反馈 (Feedback)**: 用户的每一次点击或操作都应有明确的视觉或触感反馈。
- **可点击性 (Affordance)**: 确保用户一眼看出哪些元素可以交互。
- **防错与纠错 (Error Prevention)**: 关键操作前提供确认, 错误后提供恢复路径。

## 3. 组件化思维

- **设计系统 (Design System)**: 建立原子级组件 (按钮、输入框、图标)。
- **可复用性**: 减少重复劳动, 确保开发阶段样式的统一维护。

## 4. 用户测试 (User Testing)

- **可用性测试**: 让目标用户在没有引导的情况下完成任务。
- **眼动测试 / 点击热力图**: 分析用户注意力的集中区域。
- **访谈反馈**: 收集用户在使用原型时的直观感受和困惑点。

## 5. 常规检查清单

- [ ] 关键业务流(如支付流程)是否在原型中可以走通?
- [ ] 是否考虑了所有的空状态 (Empty State) 及错误提示样式?
- [ ] 字号、间距及配色是否符合无障碍设计要求?
- [ ] 是否为主要的微交互 (Micro-interactions) 提供了动态演示?
