# SEO 优化深度指南

全面的搜索引擎优化策略,涵盖从技术基础到内容传播的全链路。

## 1. 关键词研究 (Keyword Research)

### 核心策略
- **用户意图分析**: 区分导航型(Navigational)、信息型(Informational)和交易型(Transactional)查询。
- **长尾关键词**: 竞争小、转化率高。利用工具(Google Keyword Planner, Ahrefs)寻找高价值长尾词。
- **竞争对手分析**: 识别对手排名前列的关键词并寻找内容差距。

## 2. 页面优化 (On-Page SEO)

### 关键要素
- **标题标签 (Title Tag)**: 50-60 字符,关键词前置。
- **元描述 (Meta Description)**: 15-160 字符,包含引导行动 (CTA)。
- **Header 层级 (H1-H4)**: 确保 H1 唯一且包含主关键词。
- **URL 结构**: 简洁、包含关键词、使用连字符。
- **图片优化**: 压缩大小,填写包含关键词的 `alt` 文本。

## 3. 技术 SEO (Technical SEO)

### 核心检查项
- **站点速度**: 优化 Core Web Vitals (LCP, FID, CLS)。
- **移动端友好**: 响应式设计。
- **HTTPS 协议**: 安全连接是排名因素。
- **XML 站点地图**: 帮助爬虫发现页面。
- **Robots.txt**: 正确配置屏蔽和允许访问。
- **结构化数据 (Schema Markup)**: 使用 JSON-LD 提升富媒体搜索结果展示。

## 4. 内容策略 (Content Strategy)

### E-E-A-T 原则
- **Experience**: 展现真实经验。
- **Expertise**: 展示垂直领域的专业性。
- **Authoritativeness**: 建立行业权威。
- **Trustworthiness**: 确保引文真实、数据可靠。

## 5. 外部优化与链接建设 (Off-Page SEO)

### 获取高质量外链
- **访客博客 (Guest Posting)**: 在权重高的垂直网站投稿。
- **资源链接**: 制作高质量的图表、白皮书引起自然引用。
- **Broken Link Building**: 寻找对手失效链接并提供自己的替代品。

## 6. SEO 审计清单

- [ ] 检查所有页面是否有唯一的 Title 和 Meta。
- [ ] 修复所有的 404 错误及循环重定向。
- [ ] 验证 Schema 标记在测试工具中是否通过。
- [ ] 测试移动端索引及加载性能。
