# 后端架构深度评审工作流

本文档定义了如何对一个后端系统方案进行从设计到数据库的深度质量审计流程。

## 步骤 1: 架构风险评估
- 加载 `technical-design` 技能。
- 重点审查：单点故障、横向扩展能力、缓存一致性策略、熔断降级机制。

## 步骤 2: 数据建模审计
- 加载 `database-schema` 技能。
- 重点审查：范式化是否合理、索引是否冗余、慢查询风险、数据迁移复杂度、分库分表预案。

## 3. 接口协议合规性
- 加载 `api-design` 技能。
- 重点审查：路径语义化、状态码标准、版本兼容性、敏感数据脱敏、幂等性设计。

## 4. 交付物: 架构评审报告
- 生成包含“高风险点”、“优化建议”及“实施计划”的综合性技术报告。
