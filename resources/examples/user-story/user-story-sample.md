# 示例：用户自助重置密码功能 (User Password Reset)

## 用户故事

**作为** 忘记密码的系统用户  
**我想要** 通过注册邮箱接收重置密码的链接  
**以便于** 我能安全地找回账户访问权限,无需联系人工客服

## 验收标准 (Acceptance Criteria)

### AC1: 发送重置链接
- **Given**: 用户在登录页面点击“忘记密码”。
- **When**: 用户输入已注册的邮箱并点击“发送”。
- **Then**: 系统应在 1 分钟内发送一封包含唯一重置令牌链接的邮件到该地址。
- **And**: 页面应显示“重置邮件已发送”的确认提示。

### AC2: 链接有效性与过期
- **Given**: 用户点击了邮件中的链接并在 24 小时有效期内。
- **When**: 链接被打开。
- **Then**: 页面应显示新密码设置界面。
- **And**: 令牌一旦被使用或超过 24 小时,必须立即失效。

### AC3: 密码强度验证
- **Given**: 用户处于新密码设置界面。
- **When**: 用户输入小于 8 位或不含特殊字符的密码。
- **Then**: 系统应实时显示警告提示,且“保存”按钮保持禁用状态。

## 优先级与估算
- **优先级**: Must-have (P0)
- **故事点**: 3 (中等复杂度,涉及邮件网关及令牌生成逻辑)
