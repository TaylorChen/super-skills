# 图像生成示例

## 示例 1：现实主义风格

### 输入

```
/image-gen-full
风格: realistic
尺寸: 1024x1024
描述: 一只可爱的橘猫坐在窗台上，看着窗外的日落，温暖的光线照进房间，猫的毛发呈现出金黄色的光泽，背景是城市的天际线和橘红色的天空
```

### 输出

![现实主义风格示例](https://example.com/images/cat-sunset.jpg)

## 示例 2：卡通风格

### 输入
