# 多步骤交互示例

本示例展示了如何在 Skills 中实现复杂的多步骤交互流程。

## 什么是多步骤交互

多步骤交互是指技能在执行过程中需要与用户进行多次交互，逐步收集信息并构建完整的解决方案。这种方式特别适合处理复杂的任务，如产品需求分析、技术方案设计等。

## 多步骤交互的优势

- **逐步引导** - 减轻用户一次性提供所有信息的负担
- **动态调整** - 根据用户输入动态调整后续步骤
- **错误处理** - 及时捕获和纠正用户输入错误
- **个性化** - 根据用户的具体情况提供定制化的解决方案
- **用户参与** - 增强用户对最终结果的参与感和满意度

## 多步骤交互的基本结构

### 1. 初始化步骤

**目标**: 了解用户的基本需求和期望

**示例对话**:
- **系统**: 您好！我是您的产品需求分析师。请问您需要为什么产品或功能编写需求文档？
- **用户**: 我需要为一个在线教育平台的课程推荐功能编写需求文档。

### 2. 信息收集步骤

**目标**: 收集详细的需求信息

**示例对话**:
- **系统**: 很好！为了更好地理解您的需求，我需要收集一些详细信息。
- **系统**: 1. 这个课程推荐功能的核心目标是什么？
- **用户**: 提高用户课程完成率和平台粘性。
- **系统**: 2. 您希望推荐算法考虑哪些因素？
- **用户**: 用户历史学习记录、兴趣标签、热门课程、学习进度。
- **系统**: 3. 有什么特殊的业务规则需要考虑吗？
- **用户**: 推荐的课程价格不能全部是付费课程，需要混合免费和付费课程。

### 3. 分析和处理步骤

**目标**: 分析收集到的信息，生成初步方案

**系统**: 感谢您提供的信息！我正在分析您的需求，为您生成课程推荐功能的需求文档。

### 4. 确认和调整步骤

**目标**: 与用户确认初步方案，收集反馈并进行调整

**示例对话**:
- **系统**: 基于您的需求，我已生成了课程推荐功能的初步需求文档。以下是核心内容：
  - 功能目标：提高用户课程完成率和平台粘性
  - 推荐算法考虑因素：用户历史学习记录、兴趣标签、热门课程、学习进度
  - 业务规则：推荐课程需混合免费和付费课程
  - 核心功能：个性化推荐、推荐理由、反馈机制、多样性保证
- **系统**: 请问您对这个初步方案有什么调整或补充吗？
- **用户**: 我还希望添加基于学习时间的推荐，比如在用户通常学习的时间段推荐相关课程。

### 5. 最终输出步骤

**目标**: 根据用户反馈调整方案，生成最终结果

**系统**: 感谢您的补充！我已更新了需求文档，添加了基于学习时间的推荐功能。

**系统**: 以下是完整的课程推荐功能需求文档：

[完整的需求文档内容]

## 多步骤交互的技术实现

### 在 metadata.json 中定义交互流程

```json
{
  "prompts": [
    {
      "trigger": "/multi-step-demo",
      "description": "多步骤交互示例",
      "template": "开始多步骤交互演示，帮助用户完成复杂任务。",
      "multiStep": true,
      "steps": [
        {
          "id": "step1",
          "name": "初始化",
          "description": "了解用户基本需求",
          "prompt": "您好！我是您的助手。请问您需要帮助完成什么任务？"
        },
        {
          "id": "step2",
          "name": "信息收集",
          "description": "收集详细信息",
          "prompt": "为了更好地帮助您，我需要了解更多详细信息。[具体问题]",
          "dynamic": true
        },
        {
          "id": "step3",
          "name": "分析处理",
          "description": "分析信息并生成初步方案",
          "prompt": "感谢您提供的信息！我正在分析并生成解决方案。"
        },
        {
          "id": "step4",
          "name": "确认调整",
          "description": "确认初步方案并收集反馈",
          "prompt": "基于您的需求，我已生成了初步方案。[方案摘要]\n请问您对这个方案有什么调整或补充吗？",
          "dynamic": true
        },
        {
          "id": "step5",
          "name": "最终输出",
          "description": "生成最终结果",
          "prompt": "感谢您的反馈！我已根据您的意见调整了方案。以下是最终结果：\n[最终方案]"
        }
      ]
    }
  ]
}
```

### 在 SKILL.md 中添加多步骤交互说明

```markdown
## 多步骤交互

### 交互流程

1. **初始化** - 了解用户基本需求
2. **信息收集** - 收集详细的需求信息
3. **分析处理** - 分析信息并生成初步方案
4. **确认调整** - 与用户确认方案并收集反馈
5. **最终输出** - 生成最终结果

### 使用示例

```
/multi-step-demo
我需要为在线教育平台设计课程推荐功能
```

### 预期交互流程

**步骤 1: 初始化**
- 系统: 了解用户基本需求
- 用户: 提供基本需求描述

**步骤 2: 信息收集**
- 系统: 提出具体问题
- 用户: 回答问题，提供详细信息

**步骤 3: 分析处理**
- 系统: 分析信息，生成初步方案

**步骤 4: 确认调整**
- 系统: 展示初步方案
- 用户: 提供反馈和调整建议

**步骤 5: 最终输出**
- 系统: 展示最终方案
```

## 多步骤交互的最佳实践

### 设计原则

1. **清晰的步骤结构** - 每个步骤有明确的目标和预期输出
2. **合理的步骤数量** - 控制在 3-7 个步骤之间，避免过多步骤
3. **自然的对话流程** - 模拟真实的人类对话，避免机械感
4. **及时的反馈** - 对用户的每个输入给予及时、有意义的反馈
5. **灵活的调整机制** - 允许用户在任何步骤返回修改之前的输入

### 实施技巧

1. **状态管理** - 有效管理对话状态，跟踪用户的选择和输入
2. **条件分支** - 根据用户输入动态调整后续步骤
3. **错误处理** - 优雅处理用户的无效输入或误解
4. **进度提示** - 向用户展示当前进度和剩余步骤
5. **总结能力** - 在关键节点总结已收集的信息，确保理解正确

### 常见挑战及解决方案

| 挑战 | 解决方案 |
|------|----------|
| 用户提供信息不足 | 提出具体、引导性的问题 |
| 用户偏离主题 | 温和引导用户回到当前任务 |
| 步骤过多导致疲劳 | 每 2-3 个步骤后提供进度总结，允许用户暂停和继续 |
| 用户改变需求 | 灵活调整后续步骤，重新收集相关信息 |
| 复杂信息的处理 | 使用结构化的方式组织和呈现信息 |

## 多步骤交互的应用场景

多步骤交互特别适合以下场景：

1. **产品需求分析** - 逐步收集和整理产品需求
2. **技术方案设计** - 分步骤设计复杂的技术方案
3. **问题诊断** - 逐步排查和定位问题
4. **个性化推荐** - 基于用户偏好逐步优化推荐结果
5. **教育和培训** - 引导用户完成学习过程
6. **财务规划** - 逐步收集财务信息并制定规划
7. **健康咨询** - 逐步了解健康状况并提供建议

## 示例技能

### 产品需求分析技能

**触发词**: `/product-requirements-interactive`

**交互流程**:
1. **初始化**: 了解产品基本信息
2. **目标确认**: 明确产品目标和核心功能
3. **需求收集**: 收集详细的功能需求和非功能需求
4. **分析处理**: 分析需求并生成初步文档
5. **确认调整**: 与用户确认文档内容
6. **最终输出**: 生成最终的产品需求文档

### 技术方案设计技能

**触发词**: `/technical-design-interactive`

**交互流程**:
1. **初始化**: 了解项目背景和目标
2. **约束确认**: 确认技术约束和要求
3. **方案设计**: 分步骤设计技术方案
4. **评估调整**: 评估方案并收集反馈
5. **最终输出**: 生成最终的技术方案文档

## 总结

多步骤交互是一种强大的技能设计模式，特别适合处理复杂的任务。通过合理设计交互流程，技能可以更好地理解用户需求，提供更个性化、更准确的解决方案，同时增强用户体验和满意度。

在设计多步骤交互技能时，应注重步骤的逻辑性和连贯性，确保对话自然流畅，同时提供足够的灵活性以适应不同用户的需求和偏好。
